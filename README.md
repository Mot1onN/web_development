# «FunFinder»

FunFinder — веб-сайт для подбора мест в Челябинске. Пользователь выбирает, хочет он покушать, поразвлечься или погулять, отвечает на несколько вопросов и получает список подходящих мест.

## Технологии

- ASP.NET Core и Blazor
- Entity Framework Core для работы с базой данных
- Git и GitHub, Visual Studio Code
