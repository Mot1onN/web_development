# Техническое задание

## Общее описание

Название проекта: **«Куда сходить?»**

Проект представляет собой веб-сайт, который помогает пользователю выбрать место для отдыха или приёма пищи с помощью последовательных вопросов. В начале пользователь выбирает, хочет он **покушать** или **поразвлечься**. В зависимости от выбора сайт задаёт уточняющие вопросы и в конце предлагает подходящие варианты.

Если выбрана ветка «Покушать», пользователю могут быть предложены кафе, рестораны, кофейни и другие заведения.  
Если выбрана ветка «Поразвлечься», пользователю могут быть предложены боулинг, картинг, бильярд и другие варианты досуга.

Цель проекта — упростить выбор места и сделать процесс подбора быстрым, понятным и интерактивным.

## Функции

- Стартовый экран с началом подбора.
- Выбор основной категории:
  - «Покушать»;
  - «Поразвлечься».
- Ветка «Покушать»:
  - выбор типа заведения: кафе, ресторан, кофейня и т.д.;
  - уточняющие вопросы по кухне, бюджету, расположению, компании.
- Ветка «Поразвлечься»:
  - выбор типа развлечения: боулинг, картинг, бильярд и т.д.;
  - уточняющие вопросы по количеству человек, бюджету, времени, району.
- Последовательная логика вопросов и ответов.
- Подбор подходящих мест на основе ответов пользователя.
- Вывод результатов в виде списка или карточек мест.
- Отображение информации о месте: название, категория, краткое описание, адрес.
- Возможность начать подбор заново.
- Адаптивный интерфейс для ПК и мобильных устройств.
- Хранение данных о местах, вопросах и категориях в базе данных.
- Использование Entity Framework для работы с базой данных.
- Фронтенд на Blazor.
- Бэкенд на ASP.NET.

## Стек технологий

- Backend: ASP.NET Core
- ORM: Entity Framework Core
- Frontend: Blazor
- База данных: SQL Server / PostgreSQL / SQLite — уточняется в процессе разработки
- Система контроля версий: Git, GitHub
